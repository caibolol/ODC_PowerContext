01 · 项目定位

不是资料堆，而是带来源的证据工作台。

读论文、做调研时，真正难的是“我记得看过一句话，但找不到出处”。EvidenceDesk 把摘录、来源、标签和复习状态放在同一条记录里， 再用数据库全文索引把证据找回来。

它解决什么问题

摘录散落在笔记、网页和 PDF 中，来源链接与页码容易丢失；普通搜索只能匹配页面已加载的文字，无法利用数据库索引。

复习状态也常常另开表格维护，资料与进度脱节。EvidenceDesk 用一套数据模型把“找到证据”和“复习证据”连起来。

三条实现原则

  • 01
    真实数据库所有检索走 seekdb FULLTEXT + MATCH AGAINST；数据库断连时明确报错，不退回假数据。
  • 02
    来源可追溯标题、URL、页码、标签与正文一起保存，导出 Markdown 时保留完整来源信息。
  • 03
    复习有闭环未读、已读、待复习、已掌握四种状态与备注持久化，刷新或重启后仍在。

02 · 核心功能

六件事，围绕“证据”完成闭环。

功能不追求多，而是让每条资料都能被录入、检索、复习和导出。

01 / INPUT

资料录入与来源

录入标题、来源 URL、页码、正文摘录和标签。服务端校验长度、类型与 http/https 链接，所有 SQL 使用参数绑定。

02 / SEARCH

真实全文检索

seekdb 对 body_text 与 title 建立 IK 解析器的 FULLTEXT 索引，查询用 MATCH AGAINST 返回相关度并排序。

不是前端字符串匹配

未读、已读、待复习、已掌握四种状态与备注写入数据库；没有复习行的新记录默认视为未读。

03 · 技术架构

一条清晰的查询链路：浏览器 → API → seekdb；记忆链路：复习更新 → PowerContext → 下次会话复用。

后端是 Node.js + Express。检索由 seekdb 执行（默认嵌入式原生包，可选服务端 mysql2 连接池），同一套 SQL 与 IK 解析器； 每次复习状态更新写入 PowerContext 记忆快照，启动时读回复用。没有外部模型 API，也没有付费服务；数据库层只创建 odc_qoder_ 前缀表。

04 · seekdb

真实全文索引

odc_qoder_excerpts 与 odc_qoder_review_states；FULLTEXT IK 索引。

数据库对象

  • odc_qoder_excerpts：标题、来源 URL、页码、正文、标签、时间戳
  • ft_body (body_text) 与 ft_title (title)：单列 FULLTEXT 索引
  • odc_qoder_review_states：状态与备注，按 excerpt_id 唯一关联
  • 初始化优先使用 seekdb 支持的 IK；缺少时尝试 BENG；两者都不可用则初始化明确失败
  • 不预设 MySQL ngram，也不会悄悄退回假数据或内存存储

检索路径

WHERE MATCH(e.body_text) AGAINST(? IN NATURAL LANGUAGE MODE) OR MATCH(e.title) AGAINST(? IN NATURAL LANGUAGE MODE) ORDER BY title_score * 2 + body_score DESC

两个单列 MATCH 条件与两个单列索引一一对应，避免“索引列集合不匹配”的错误。

✓
真实数据库验证：在本机 seekdb 5.7.25-OceanBase seekdb-v1.4.0.0 上实测，IK 解析器同时命中中文与英文查询；BENG 命中英文；最终索引使用 IK。

05 · 运行与复现

四条命令启动，六个步骤体验完整流程。

默认连接 127.0.0.1:2881 的 test 数据库，root 用户、空密码；连接参数均可通过环境变量覆盖。

更快复现：Linux/macOS 在 qoder 目录执行 bash scripts/bootstrap.sh，一条命令完成「安装并启动 seekdb → 建表与 IK 索引 → 导入样例 → 启动服务」；Windows 执行 powershell scripts/bootstrap.ps1 -SeekdbExe <seekdb.exe 路径>。免部署体验请直接打开 在线体验。
  1. 安装依赖在项目目录执行 npm install，使用已生成的 package-lock.json。
  2. 配置数据库复制 .env.example 为 .env；默认值为 seekdb 127.0.0.1:2881 / test / root / 空密码。
  3. 初始化表与索引执行 npm run db:init，创建 odc_qoder_ 前缀表与 IK FULLTEXT 索引。
  4. 启动应用执行 npm start，默认只监听 127.0.0.1:18748。
  5. 体验功能导入合成样例，搜索“分布式数据库”，设置复习状态，导出 Markdown。
  6. 运行测试执行 npm test，得到 84 项真实 seekdb 集成测试结果。
