实测中遇到并解决的问题（评审在有代理的环境会遇到同样情况）
  1. dockerd 不继承 shell 的 http_proxy 环境变量，直接 pull 会报
     "TLS handshake timeout"。解决办法是给 daemon 配代理：
         mkdir -p /etc/systemd/system/docker.service.d
         cat > /etc/systemd/system/docker.service.d/http-proxy.conf <<EOF
         [Service]
         Environment="HTTP_PROXY=http://127.0.0.1:7897"
         Environment="HTTPS_PROXY=http://127.0.0.1:7897"
         Environment="NO_PROXY=localhost,127.0.0.1,::1,172.16.0.0/12,10.0.0.0/8,192.168.0.0/16"
         EOF
         systemctl daemon-reload && systemctl restart docker
     没有代理的环境不需要这一步。
  2. 容器内 seekdb 冷启动很快（本次约 2 秒端口就绪，日志显示第 3 次探测 SQL ready），
     但 README 仍写"约 1 分钟"，run_demo.py 第一步的 wait-services 会自行等待（默认 180 秒），
     因此不需要手工等待。
